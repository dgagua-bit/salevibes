# Georgia Guide — საქართველოს ტურისტული გიდი

ჯიბის ვებ-აპლიკაცია (PWA) საქართველოში ჩამოსული ტურისტისთვის. აეროპორტში QR კოდის დასკანერებით იხსნება ბრაუზერში, „Add to Home Screen“-ით ინსტალირდება და ინტერნეტის გარეშეც მუშაობს (რუკის ფილების გარდა).

ენები: ინგლისური (ნაგულისხმევი), ქართული, რუსული — გადამრთველი header-ში, არჩევანი ინახება.

## გვერდები

| ფაილი | დანიშნულება |
|---|---|
| `index.html` | მთავარი: „ახლა ჩამოვედი“ / მარშრუტის არჩევა, რეგიონები (მთა, ზღვა, ქალაქი, ღვინო), პოპულარული მარშრუტები, ყველა ადგილი რუკაზე |

| `plan.html` | არჩეული მარშრუტები + შენახული ადგილები + ყველა გასაჩერებელი ერთ რუკაზე; ბმულით გაზიარება (`?r=…&p=…`), ბეჭდვა |

## მონაცემები (`assets/js/data/`)

- `places.js` — ადგილები (`id, name{en,ka}, region, type[], cat, lat, lng, alt, desc, tips, visit, fee, hours, season, getThere`)
- `stops.js` — რესტორნები, კაფეები, მარნები, ბაზრები, გასაჩერებლები (`kind, price 1–3, near → place id`)
- `routes.js` — მარშრუტები: `itinerary[day].stops[{place, drive|walk, note}]`, `eat[]`, `rest[]`, `practical[]`
- `food.js` — კერძები, სასმელები, სუფრა, ფრაზები, ფასები
- `arrival.js` — აეროპორტები და ვარიანტები, SIM, ფული, 112, აუცილებელი

ფასები და განრიგი საორიენტაციოა (2025–26) — UI ყველგან წერს „გადაამოწმე ადგილზე“. ახალი ადგილის/მარშრუტის დასამატებლად საკმარისია შესაბამის ფაილში ჩანაწერის დამატება; `tests/guide.unit.test.mjs` ამოწმებს, რომ ყველა ბმული ID არსებობს, კოორდინატები საქართველოშია და en+ka ტექსტი სრულია.

## ტექნიკური

- სტატიკური, build-ის გარეშე (ES modules). Leaflet 1.9.4 და qrcode-generator vendored-ია (`assets/vendor/`), რომ offline-ზეც იმუშაოს.
- `sw.js` — app shell-ის precache + OSM ფილების runtime cache; `manifest.webmanifest` — ინსტალაცია, shortcuts.
- რუკა: OpenStreetMap ფილები (ინტერნეტი სჭირდება), მომხმარებლის ლოკაცია ⌖ ღილაკით.
- GitHub Pages-ზე მისამართია `…/salevibes/guide/`; ცალკე დომენზე გადასატანად მთელი `guide/` საქაღალდე საკმარისია.
